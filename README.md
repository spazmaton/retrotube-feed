# RetroTube Feed

Я сделал Atom-фид для [RetroTube](https://retrotube.net), чтобы следить за новыми видео через мой читатель лент.

Сейчас в ленту попадают 15 последних видео. У каждой записи есть название, автор, дата публикации и ссылка на просмотр. Фид формируется при каждом запросе на основе API RetroTube.

## Как пользоваться

Добавьте адрес развёрнутого Worker в читалку с поддержкой Atom. Лента доступна по корневому адресу Worker — отдельный путь `/feed` не нужен.

## Локальный запуск

Проект написан на JavaScript и работает на Cloudflare Workers. Для локального запуска нужны Node.js и npm.

```sh
npm install
npm run dev
```

Откройте адрес, который выведет Wrangler, чтобы посмотреть XML-фид. Для получения видео нужен доступ к API RetroTube.

## Развёртывание

Для публикации в своём аккаунте Cloudflare:

```sh
npx wrangler login
npm run deploy
```
