# RetroTube Feed

Atom-фид для [RetroTube](https://retrotube.net), чтобы следить за новыми видео И УВЕДОМЛЕНИЯМИ через читатель лент.

Доступны две отдельные ленты: 15 последних видео И ПЕРВАЯ СТРАНИЦА УВЕДОМЛЕНИЙ. Количество уведомлений на странице определяется API RetroTube и не обязательно равно семи. У каждой записи есть название, автор и дата публикации. Ссылка на просмотр есть только у видео; в уведомлениях дополнительно выводится текст. Фиды формируются при каждом запросе на основе API RetroTube.

## Как пользоваться

Добавьте нужный адрес развёрнутого Worker в читалку с поддержкой Atom:

- Видео: `https://YOUR-WORKER.YOUR-SUBDOMAIN.workers.dev/`
- Уведомления: `https://YOUR-WORKER.YOUR-SUBDOMAIN.workers.dev/notifications-test`

Замените `https://YOUR-WORKER.YOUR-SUBDOMAIN.workers.dev` на фактический адрес своего Worker, который выведет Wrangler после развёртывания. Для видео используется корневой адрес `/` — отдельный путь `/feed` не нужен. Чтобы получать обе ленты, добавьте оба адреса.

## Настройка уведомлений

Имя аккаунта задаётся переменной `RETROTUBE_USERNAME`, а refresh-токен — `RETROTUBE_REFRESH_TOKEN`. Менять исходный код не нужно. Имя и токен должны относиться к одному аккаунту RetroTube.

Для локального запуска создайте файл `.dev.vars` рядом с `package.json`:

```dotenv
RETROTUBE_USERNAME="ВАШ_ЛОГИН"
RETROTUBE_REFRESH_TOKEN="ВАШ_REFRESH_TOKEN"
```

Имя файла начинается с точки: `.dev.vars`. Он уже добавлен в `.gitignore`; не публикуйте его и не вставляйте настоящий токен в исходный код. После изменения `.dev.vars` перезапустите локальный Worker. Если `RETROTUBE_USERNAME` не задан или пуст, маршрут уведомлений вернёт ошибку `503` с пояснением. Для ленты видео имя аккаунта и токен не требуются.

## Локальный запуск

Проект написан на JavaScript и работает на Cloudflare Workers. Для локального запуска нужны Node.js и npm.

```sh
npm install
npm run dev
```

Откройте адрес, который выведет Wrangler, чтобы посмотреть XML-фид видео. Для уведомлений добавьте к этому адресу `/notifications-test`. Для обеих лент нужен доступ к API RetroTube.

## Развёртывание

Для публикации в своём аккаунте Cloudflare:

В `wrangler.jsonc` замените закомментированный пример `// "vars": ...` на настройку своего имени аккаунта. Также поставьте запятую после существующей строки `"upload_source_maps": true`, чтобы отделить её от нового поля `vars`:

```json
"vars": {
    "RETROTUBE_USERNAME": "ВАШ_ЛОГИН"
}
```

Логин хранится как обычная переменная, токен — как секрет. Затем выполните:

```sh
npx wrangler login
npx wrangler secret put RETROTUBE_REFRESH_TOKEN
npm run deploy
```

Команда `secret put` попросит ввести refresh-токен и сохранит его как секрет Worker. Файл `.dev.vars` используется только локально; при развёртывании он не заменяет настройку секрета в Cloudflare. Если нужна только лента видео, команду `secret put` можно пропустить.
